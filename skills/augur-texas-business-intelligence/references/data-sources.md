# Augur Data Sources

Track source URLs, dataset IDs, access methods, refresh expectations, and citation rules here as connectors are implemented.

Initial source priorities:
- OpenStates API for Texas bill discovery and metadata.
- Texas Legislature Online RSS for daily change detection.
- Texas Legislature Online FTP for official bill text, analyses, fiscal notes, reports, histories, and witness lists.
- Texas Ethics Commission downloads for lobbying/public activity snapshots.
- Austin Socrata datasets for issued construction permits and zoning cases.
- Dallas Socrata datasets for permits, certificates of occupancy, and code violations.
- San Antonio CKAN/API/download resources for permits and land-use context.
- Houston CKAN resources if connector quality is acceptable.
